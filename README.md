# Skypro Kanban

Учебное Kanban-приложение для управления задачами, выполненное на React.

## Функциональность

- регистрация и вход пользователя;
- защищённые маршруты для авторизованных пользователей;
- Kanban-доска с распределением задач по статусам;
- создание, просмотр, редактирование и удаление задач;
- валидация обязательных полей и защита от отправки строк из одних пробелов;
- обработка ошибок API и проблем с соединением;
- состояние загрузки и сообщение при пустом списке задач;
- страница 404 с переходом на главную.

## Стек

- React
- Vite
- React Router
- styled-components
- Axios

## Запуск проекта

```bash
npm install
npm run dev
```

## Проверка перед сборкой
