# Проверка адаптивности — 21.10.2026

База: `development`, коммит `21d7babbb0bbf270c2c4e84ef3a11aed4ce30883`. Содержимое `master` на момент проверки совпадает с этой веткой; `main` содержит только `.gitignore`. Открытых PR на момент начала работы не обнаружено. База нового PR — существующая рабочая `development`.

## Дефекты со скриншотов

- Карточка имела `height: 130px`, блок текста — `height: 64px`. Длинный заголовок выталкивал дату, а следующие карточки налезали на текст. Теперь карточка и текст растут по содержимому; ширина связана с колонкой, слова без пробелов переносятся. Минимальная высота короткой карточки сохранена.
- Шапка ограничивала навигацию 290 px. На 768/1024/1440 кнопка создания сжималась до 74 px: высота текста 51 px при высоте кнопки 30 px. Теперь кнопка не сжимается, центрируется и растёт по тексту; длинный профиль занимает оставшееся место с многоточием.
- Меню профиля имело фиксированные ширину/высоту и не переносило адреса. Теперь панель ограничена шириной экрана, растёт по содержимому; имя и логин выведены в правильном порядке. Совпадающие значения показаны один раз. Добавлены Escape, возврат фокуса и закрытие по клику снаружи.
- При переходе из шапки на 320 px найдены связанные переполнения: минимальная ширина оверлеев 375 px, ширина календаря 344 px, непереносимые категории. Оверлеи теперь помещаются в экран, календарь использует семь гибких колонок, категории переносятся. Добавлен нижний отступ для закреплённой мобильной кнопки.

Размеры иконок, отступы и минимальные размеры не удалялись механически: исправлены ограничения, мешавшие содержимому и адаптивности. Существующая композиция доски (колонки на большом экране, горизонтальные ряды карточек под статусами на узком) сохранена.

## Проверки

- Чистая установка по package-lock, Node.js 24.19.0; `npm run lint`, `npm run build`, `npm test`.
- 6 браузерных регрессионных тестов: 320/375/390/768/1024/1440, Edge, штатный Roboto.
- В каждом: все пять статусов, длинный заголовок с пробелами, длинное слово, короткая следующая карточка; геометрия текста/дат внутри фона и отсутствие пересечения карточек.
- Проверены длинный адрес в шапке, одинаковые имя/логин и разные длинные значения в профиле, видимость кнопки создания, Escape с возвратом фокуса, закрытие меню снаружи, открытие/закрытие новой задачи и карточки.
- 24 снимка: доска, профиль, новая задача, просмотр карточки на каждой ширине. Автоматические проверки дополнены просмотром снимков 320/768/1440.
- Контролируемые GET-ответы API и синтетическая сессия. Реальный CRUD, drag-and-drop и точное сравнение с Figma этим прогоном не подтверждаются. Исходный макет не предоставлен; приложенные скриншоты использованы как подтверждение дефектов.

Исходные бизнес-операции API не менялись. Новая зависимость Playwright используется только при разработке. Новые PR не объединяются без согласования.
